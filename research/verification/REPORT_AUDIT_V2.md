## 2. Standardized Context-Size Accounting Definitions

To eliminate unit ambiguity going forward, all experiments must explicitly record:
1. **Total Corpus Size**: The full unpruned source text / codebase size (in characters and estimated tokens).
2. **Context Available to Request**: The portion of the corpus accessible to the specific request.
3. **Context Sent by Baseline**: The actual prompt payload sent in the baseline condition.
4. **Context Selected by NeuralPack**: The optimized prompt payload generated by the execution planner.
5. **Model-Reported Prompt Tokens**: The authoritative `prompt_tokens` returned by the provider API.

## 3. Scope Boundaries & Remaining Deficits
- **Sample Size Deficit**: Testing 10 live code tasks and 50 mock holdout tasks is an encouraging proof-of-concept, but does not prove robustness across hundreds of unseen, diverse workloads.
- **Competitor Baseline Deficit**: Standard BM25 is an entry-level baseline. Competitors must include tuned dense embeddings, hybrid retrieval, and code-aware symbol maps.
- **Adversarial Deficit**: An 80% critical-context recall rate in noisy environments means 20% of required context blocks were dropped, which would cause production failures. This must be attacked algorithmically.
